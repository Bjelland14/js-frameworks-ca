# JavaScript Frameworks Course Assignment

## Description

This project is an online shop built with React, TypeScript, and Vite.

Users can browse products, search and sort products, view product details, add products to a shopping cart, adjust quantities, complete a checkout flow, and send messages through a validated contact form.

The application uses the Noroff Online Shop API to fetch product data.

## Features

- Product browsing
- Product details
- Search functionality
- Sorting functionality
- Shopping cart
- Adjustable quantities
- Remove items from cart
- Cart total calculation
- Checkout success page
- Contact form validation
- Responsive design

## Built With

- React
- TypeScript
- Vite
- React Router
- CSS
- Noroff Online Shop API
